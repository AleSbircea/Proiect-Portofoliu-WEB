# Portofoliu Web - Sbîrcea Elena Alexandra

Site personal de portofoliu cu integrare GitHub API.

## Demo live
[https://alesbircea.github.io/Proiect-Portofoliu-WEB/](https://alesbircea.github.io/Proiect-Portofoliu-WEB/)

## Tehnologii folosite
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Fetch API, DOM manipulation)
- GitHub REST API

## Funcționalități
- Profil personal cu poză, descriere și competențe
- Educație și experiență profesională
- Proiecte încărcate dinamic din GitHub API
- Fallback cu proiecte demo dacă API-ul nu răspunde
- Loading spinner în timp ce se încarcă proiectele
- Error handling cu mesaj prietenos
- Sortare după data actualizării sau număr de stele
- Căutare în timp real după numele proiectului
- Buton Load More pentru proiecte suplimentare
- Design responsiv pentru telefon, tabletă și desktop

## Instalare locală
1. Clonează repository-ul: https://github.com/AleSbircea/Proiect-Portofoliu-WEB 
2. Deschide folderul în VS Code
3. Pornește XAMPP și accesează: file:///C:/xampp/htdocs/Proiect%20Portofoliu-WEB/
